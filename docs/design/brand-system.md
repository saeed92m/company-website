# Brand System — Alpha Team

## Source-of-truth inputs

The current brand reference set is stored in the project's Dropbox folder `/company website`:

- `Logo.png`
- `wordmark.png`
- `Color Code.JPEG`
- `wallpapers/` (8 approved wallpaper references)

The supplied color reference identifies:

- Primary blue: `#003C91`
- Neutral grey: `#A8A8A8`

The visual reference explicitly presents the name **ALPHA TEAM** with the supplied mark.

## Identity architecture

- **Public brand:** ALPHA TEAM
- **Legal identity:** شرکت پیشگامان نواندیش فناورگستر کیهان (مسئولیت محدود)
- The legal identity remains authoritative for corporate/legal disclosures.
- `Alpha Team Startup` is not used as the current public brand name.

## Web usage

- Use the Alpha mark as the primary compact brand identifier.
- Use the ALPHA TEAM wordmark in the header when horizontal space permits.
- Keep the legal company name in appropriate corporate/footer contexts.
- Do not replace source brand colors with arbitrary theme colors.
- Maintain sufficient contrast and visible focus states.
- Do not use wallpapers as decorative content unless they improve hierarchy and remain performant.

## Implementation note

The web repository contains lightweight SVG web assets derived from the supplied visual reference so the initial frontend does not depend on temporary Dropbox URLs. The Dropbox source remains the brand reference; the original raster files are not copied into the repository as proprietary source material.
