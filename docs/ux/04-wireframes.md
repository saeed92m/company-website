## Responsive rules

- Mobile-first layout.
- No horizontal scrolling.
- Navigation must remain accessible at all viewport sizes.
- Six domains must remain discoverable on mobile.
- RTL/LTR must affect layout direction, alignment, icons, navigation, and forms correctly.
- Long translated strings must not break controls.

## Accessibility rules

- Semantic landmarks.
- One logical H1 per page.
- Keyboard-operable navigation.
- Visible focus.
- Accessible language selector.
- Form labels and error messages.
- Reduced-motion support.
- Logical reading order in both RTL and LTR.
