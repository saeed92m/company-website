# Content Source of Truth

## Purpose
Define the evidence hierarchy for public corporate website content and prevent stale source documents from overriding current approved information.

## Source hierarchy
### 1. Explicitly approved current project decisions
The latest explicit decisions provided by the company/project owner take precedence when they intentionally update or supersede an older document.

### 2. Current supplied CEO resume
The current supplied resume of Saeed Memarzadeh is the authoritative source for the CEO's professional biography, education, experience, projects, publications, skills, memberships, courses/certificates, and professional languages.

The current resume also states that the company is active across six domains:
1. Astronomy
2. Aerospace
3. Renewable Energy
4. Artificial Intelligence
5. Motorsport & Performance Parts
6. Remote Sensing

### 3. Current approved company profile
The company profile is authoritative for corporate identity and registration facts where it has not been superseded by an explicit current project decision.

If an older company-profile statement conflicts with a newer approved company/project decision, the newer decision governs the website content and the discrepancy must be documented rather than silently reconciled.

## Publication rules
- Never invent corporate facts, capabilities, clients, partnerships, awards, metrics, or technical achievements.
- Do not treat stale wording in an older source as a blocker when the project owner has explicitly confirmed the current information.
- Do not expose private contact details or other sensitive personal information from the resume without approval.
- Keep project status factual and avoid implying completion where the source does not support it.
- Alpha Linux and ZTF Classifier may be introduced publicly, but repository URLs remain unpublished until explicitly approved.
- Preserve the distinction between company identity and future legal/organizational changes; do not make legal claims that are not supported by the current approved source set.

## Current CEO content source
Primary: current supplied resume (resume_saeed_memarzadeh.pdf / Persian resume).

Secondary: company profile only for corporate context that is not superseded.

## Review trigger
Re-review this source hierarchy whenever:
- a new resume/CV is supplied;
- the company profile is materially updated;
- the project owner explicitly changes a corporate fact;
- a legal/registration fact is intended for publication;
- a public project status changes.
