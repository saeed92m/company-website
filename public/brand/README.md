# Brand Assets

This directory documents the approved company brand assets used by the website.

## Source of truth

The exact source files supplied for this project are:

- `Logo - Color Code.JPEG` — supplied color-reference artwork.
- `Logo-1 (1).png` — supplied high-resolution logo artwork.

These source files must not be redrawn, recolored, stretched, or otherwise altered when used as the official mark.

## Approved colors

- Primary Blue: `#003C91`
- Brand Gray: `#A8A8A8`

## Current identity decision

The registered company name is the primary website identity. Alpha Team is not a registered company name or primary site brand. It may appear only as a secondary team/project reference where supported by source material. See ADR 0008.

## Current web derivative

The current site keeps a lightweight vector derivative for the shell/favicon so the initial Pages build remains small and base-path safe. It is **not** a replacement for the supplied source artwork.

The exact supplied binary logo must be confirmed and added through a reviewed asset-ingestion change before final brand QA. A transparent PNG derivative was prepared for owner review outside the repository; it is not yet approved or committed. Until the owner approves the final asset, the current vector derivative must not be treated as the canonical master logo.
